🏆 스도쿠 순위표

스도쿠란?

스도쿠는 스위스에서 유래한 숫자 퍼즐이지만, 1980년대에 한 일본 출판사가 널리 알리면서 전 세계적으로 유명한 논리 퍼즐이 되었습니다. 9x9 판은 9개의 3x3 박스로 나뉘며, 목표는 빈칸에 1부터 9까지의 숫자를 채워 넣되 같은 행, 같은 열, 같은 박스 안에서 숫자가 겹치지 않게 하는 것입니다. 이 버전의 모든 문제는 정해진 문제집이 아니라 웹페이지에서 그때그때 자동으로 생성되므로, 이론적으로 문제가 절대 바닥나지 않습니다.

난이도가 계속 올라갑니다

한 문제를 풀면 자동으로 다음 문제로 넘어가며, 난이도는 쉬움 → 보통 → 어려움을 거쳐 마지막으로 전문가까지 순서대로 올라간 뒤, 그 이후로는 전문가 난이도가 계속 유지됩니다. 난이도는 주로 남겨두는 초기 힌트 숫자의 개수로 조절되며, 힌트가 적을수록 보통 더 많은 논리적 추론이 필요합니다. 모든 문제가 반드시 풀 수 있다는 것을 보장하면서도, 뚜렷하게 단계적으로 어려워지도록 의도적으로 설계되었습니다.

플레이 방법

숫자를 넣고 싶은 칸을 눌러 선택한 뒤, 키보드로 1부터 9까지 눌러(또는 화면 아래 숫자 패드를 눌러) 입력합니다. Backspace, Delete 또는 숫자 패드의 '지우기' 버튼으로 해당 칸을 비울 수 있습니다. 회색 배경의 숫자는 문제 자체가 제공하는 힌트로 수정할 수 없으며, 흰색 칸이 직접 채워야 하는 칸입니다. 입력한 숫자가 같은 행, 열, 박스 안의 다른 숫자와 겹치면 빨간색으로 표시되어 알려주지만 입력 자체를 막지는 않으므로, 바로 고칠지 나중에 처리할지는 스스로 정하면 됩니다. 모두 정확히 채우면 자동으로 완료 처리되고 이어서 다음 문제가 시작됩니다.

힌트와 다시 시작

막혔을 때는 '힌트'를 누르면 게임이 자동으로 한 칸에 정확한 숫자를 채워줍니다(대신 점수가 조금 깎이고, 힌트로 채워졌다는 걸 알 수 있도록 다른 색으로 표시됩니다). '내 입력 지우기'는 직접 입력한 숫자만 모두 지우고 원래 주어진 힌트는 그대로 남겨두어, 처음부터 다시 추론해 볼 수 있게 해줍니다.

자주 묻는 질문

이 스도쿠 게임의 규칙은 무엇인가요?
9x9 판은 9개의 3x3 박스로 나뉩니다. 목표는 각 행(가로 9칸), 각 열(세로 9칸), 각 3x3 박스에 1부터 9까지의 숫자가 정확히 한 번씩만 나오고 겹치지 않도록 1부터 9까지의 숫자를 채워 넣는 것입니다.
모든 스도쿠 문제가 반드시 풀 수 있게 보장되나요?
반드시 풀 수 있고, 해도 반드시 유일합니다. 이 버전의 문제는 먼저 프로그램으로 완전한 정답을 만든 뒤 숫자를 지워 힌트를 만드는 방식으로 생성됩니다. 지우는 과정에서 풀이 알고리즘이 남은 힌트가 여전히 오직 하나의 해에만 대응하는지 확인한 뒤에야 정식으로 문제가 출제되므로, 풀 수 없거나 답이 여러 개인 문제는 나오지 않습니다.
난이도는 어떻게 나뉘나요?
난이도는 주로 판에 남아 있는 초기 힌트(주어진 숫자) 개수로 나뉩니다. 힌트가 많을수록 보통 더 쉽고, 힌트가 적을수록 보통 더 복잡한 추론이 필요합니다. 이는 단순화된 난이도 추정 방식으로, 완전한 풀이 기법 분류는 아닙니다(예를 들어 XY-Wing 같은 고급 기법이 필요한 문제를 특별히 구분하지는 않습니다). 하지만 쉬움부터 전문가까지 뚜렷하고 점진적인 난이도 곡선을 만들기에는 충분합니다.
난이도가 끝없이 계속 올라가나요?
네. 첫 문제(쉬움)를 풀고 나면 자동으로 다음 문제로 넘어가며, 쉬움 → 보통 → 어려움 → 전문가 순서로 올라간 뒤 이후로는 전문가 난이도가 유지됩니다. 문제 품질이 불안정해질 정도까지 힌트 수를 무한정 줄이지는 않으므로, 모든 문제가 안정적으로 풀리는 범위 안에서 난이도가 최대한 올라갑니다.
힌트 버튼은 어떤 기능인가요?
'힌트'를 누르면 게임이 자동으로 판의 한 칸에 정확한 숫자를 채워주지만, 대신 점수가 조금 깎입니다. 그 칸은 직접 입력한 숫자와 구분할 수 있도록 다른 색으로 표시됩니다.
