## 2. softglow 的 `backend/main.py` 加這一段

插入位置：第 581 行之後（CORS middleware 設定完、`_FRONTEND_DIR` 定義之前）。
可以直接放在 `WwwRedirectMiddleware` 那段附近，風格一致方便對照。

```python
# ---- 學測評量系統子服務（獨立package，quiz/，失敗不影響主站） ----
try:
    from quiz.main import app as _quiz_app
    app.mount("/quiz-api", _quiz_app)
    print("✅ quiz 學測評量子服務已掛載")
except Exception as _e:
    print(f"⚠️ quiz 學測評量子服務載入失敗（不影響主站）：{_e}")

# ---- quiz.softglow-ai.com 子網域 → 內部轉發到 /quiz-api（不是redirect，網址列不變） ----
class QuizHostRewriteMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        host = request.headers.get("host", "")
        if host.startswith("quiz.") and not request.url.path.startswith("/quiz-api"):
            request.scope["path"] = "/quiz-api" + request.url.path
        return await call_next(request)

app.add_middleware(QuizHostRewriteMiddleware)
```

用 bytes 層級（rb/wb）+ 精確比對 CRLF 換行插入，跟過去改 main.py 的習慣一致。

## 4. Zeabur 環境變數（在 softglow 這個既有服務裡加，不是開新服務）

| 變數 | 值 |
|---|---|
| `SUPABASE_URL` | 建立 Supabase 專案後從 Project Settings → API 複製 |
| `SUPABASE_KEY` | 同上，複製 anon public key |
| `QUIZ_ALLOWED_ORIGINS` | 之後前端網址，例如 `https://quiz.softglow-ai.com` |

⚠️ 注意是 `QUIZ_ALLOWED_ORIGINS`，不是 `ALLOWED_ORIGINS`——softglow 主站已經在用
`ALLOWED_ORIGINS` 這個名字，兩邊共用會互相干擾。這代表 `quiz/main.py`
目前的草擬版**故意沒有自己讀環境變數**（CORS已交給外層主站處理），如果之後
還是想讓 quiz app 保留獨立 CORS 設定，要記得改讀 `QUIZ_ALLOWED_ORIGINS`
而不是 `ALLOWED_ORIGINS`。
