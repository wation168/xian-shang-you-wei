## 這次補查到的技術事實：會員權限系統（GPT問的，Grok已經做了）

查了後端 `main.py`，會員分層是真的已經做好、不是空殼：
- 遊客（未登入）：個股查詢／完整分析每日 **3** 次（`GUEST_DAILY_LIMIT=3`）
- 免費會員（登入）：完整分析＋持股健檢**共用**每日 **5** 次額度（`FREE_DAILY_LIMIT=5`）
- 付費會員（月費／季費／年費三種方案）：不消耗額度，無限使用
- **深度分析／型態細節這類，是直接整個鎖住，跟每日額度無關**——不是免費用完5次才鎖，是免費會員本來就看不到
- V2的會員身分切換器、鎖定邏輯，都是照這套真實規則做的，不是我編的

## 逐點回應GPT的12項意見

| GPT意見 | V2怎麼處理 |
|---|---|
| 1-2. 不要只是普通SaaS白卡片Dashboard | 建立光源/層次系統（三級陰影+頂部高光模擬受光面），背景加帳本紙格線，卡片有真的立體感不是純圓角陰影 |
| 3. 強化品牌辨識度 | 維持既有紅漲綠跌+品牌綠，但深色模式做成「電子看板」質感（深藍底+發光色+跑馬燈），淺色模式是「帳本紙」質感，兩種模式各自有識別度 |
| 4. 真正2D→2.5D層次 | 頂部高光inset模擬受光面、卡片hover浮起、「今天看什麼」三卡hover有3D傾斜(perspective+rotateX/Y)、DEEP區用堆疊卡片(::before疊一張在後面)做縱深 |
| 5. 卡片/按鈕/圖表要有明確層級與互動感 | 全部按鈕/卡片都有hover位移+陰影變化，sector強弱條進場動畫，指數卡內嵌sparkline |
| 6. 「想分析一檔股票」要是首頁核心入口 | 直接縫進主視覺(hero)內，第一屏就看到，不用滑到第四區 |
| 7. 「我的投資」要像真正儀表板 | 拆成「總損益／資產配置圓環／自選+健檢」三塊拼成一個儀表板，不是分散卡片 |
| 8. 三張今天看什麼要更有互動感 | 加了hover 3D傾斜、即時更新小圓點動畫、鎖定veil浮層 |
| 9. DEEP區轉換感要更強 | 「訊號已觸發」chip先勾住好奇心，內容用漸層裁切露出一半，鎖在懸念點上，不是整塊打碼 |
| 10. 免費/付費差異要能直接感受到 | 做了「預覽會員身分」互動切換器（遊客/免費/付費），切換後開盤精選、深度選股、自選健檢、DEEP區的鎖定狀態即時變化；頂部有真實額度條「今日分析額度2/5」 |
| 11. 不做裝飾性假按鈕 | 所有按鈕點擊都會跳出提示，標明實際對應哪個既有函式（如`_homeGo('picks')`），已用「技術對照」開關逐一標註 |
| 12. 桌面/手機都要成立 | 三張卡在手機版收成單欄、儀表板收成單欄，已截圖確認 |
